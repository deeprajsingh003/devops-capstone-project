# DevOps Capstone Project

[![CI Build](https://github.com/deeprajsingh003/devops-capstone-project/actions/workflows/main.yml/badge.svg)](https://github.com/deeprajsingh003/devops-capstone-project/actions)

## Description
This repository contains the Customer Accounts Microservice developed for the DevOps Capstone Project. It provides a RESTful API for managing customer accounts and is built with automated CI/CD pipelines, Docker containerization, and Kubernetes deployment.
