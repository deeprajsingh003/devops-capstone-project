![CI Build](https://github.com/<YOUR_GITHUB_USERNAME>/customer-accounts-microservice/actions/workflows/ci-build.yaml/badge.svg)

## Overview
This repository contains the Customer Accounts microservice developed for the DevOps Capstone Project. It applies key concepts of software development, automation, and cloud deployment. 

## Features
- **RESTful APIs:** Full CRUD operations for customer accounts.
- **Test-Driven Development (TDD):** Comprehensive unit testing with `nosetests` and code coverage.
- **Code Quality:** Linting configured with Flake8 and Pylint.
- **Continuous Integration (CI):** Automated testing and linting via GitHub Actions.
- **Security:** Security headers and CORS policies implemented using Flask-Talisman.
- **Containerization & Deployment:** Built with Docker and deployed to Kubernetes.
- **Continuous Delivery (CD):** Automated deployment pipelines using Tekton.

## Status
This project is currently in development for the capstone assignment.
